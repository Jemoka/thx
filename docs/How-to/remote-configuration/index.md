# Remote Configuration

Configure where remote jobs run and how they access shared files.

- [Provider Configuration](providers.md) — set up SSH, SLURM, or Volcano providers, hardware capacity, and worker environments. Start here to configure remote execution.
- [JuiceFS Integration](juicefs.md) — mount an existing JuiceFS volume so workers share data, checkpoints, and the object store.

Once your infrastructure is configured, follow the [remote training tutorial](../../Tutorials/remote.md) to submit a job.
